# Tutoriales del vault de organizadores de HubIA

Sitio estático con tres tutoriales interactivos para organizadores, incluidos quienes no tienen perfil técnico:

1. **Instalar:** GitHub, Git, VS Code y Obsidian, y traer el vault a la compu.
2. **Explorar Obsidian:** interfaz, enlaces, Bases, propiedades, búsqueda y grafo.
3. **Git con VS Code:** pull, commit, sync, conflictos y ramas.

Las pantallas son simulaciones. Las notas y las filas de las tablas son de ejemplo: el contenido real del vault sigue solo en su repositorio privado.

No necesita compilación. Para probarlo: `python3 -m http.server` y abrir `http://localhost:8000`.
